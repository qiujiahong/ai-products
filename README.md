# AI 产品经理转型项目

本项目用于系统化推进「AI 产品经理 / AI Agent 产品经理 / AI 平台产品经理」转型：明确目标岗位、能力模型、30 天冲刺计划、作品集项目和复盘机制。

## 你应该怎么读这个项目

如果你是第一次打开这个项目，建议按下面顺序推进：

1. **先确定方向**：阅读 [目标岗位、定位与阶段成果](docs/01-targets-and-positioning.md)，明确 30 天内要主攻的岗位方向和作品集目标。
2. **再盘点能力**：阅读 [AI 产品经理能力地图](docs/02-skill-map.md)，对照能力项找出当前最需要补齐的 3 个短板。
3. **按 30 天执行**：阅读 [30 天学习与作品集冲刺路线图](docs/03-30-day-roadmap.md)，把每周要交付的材料拆成每天的行动。
4. **选择作品集项目**：阅读 [作品集项目选题与交付标准](docs/04-portfolio-projects.md)，确定第一个可展示项目。
5. **同步准备求职材料**：阅读 [简历、面试与故事素材准备](docs/05-interview-and-resume.md)，把作品集转化成简历和面试表达。
6. **今天立刻开始**：打开 [今天开始学习的具体行动](docs/06-start-today.md)，完成 Day 1 的岗位样本库和项目选择。
7. **每天记录进展**：使用 [每日学习记录模板](templates/daily-learning-log.md)，并把记录放到 [`tracker/daily/`](tracker/daily/)；同时更新 [每日学习记录索引](tracker/daily-learning-index.md)。
8. **每周复盘调整**：每周填写 [每周复盘与进度追踪](tracker/weekly-review.md)，判断是否需要调整方向、节奏或作品集范围。

## 项目目标

- 在 30 天内形成 1 个可展示的 AI 产品经理核心作品集项目，并补充 1 个轻量案例拆解。
- 建立 AI 产品从机会识别、数据与模型评估、PRD、实验设计到上线复盘的完整方法论。
- 形成面向目标岗位的简历素材、面试故事和可量化成果。

## 推荐主攻方向

1. **LLM 应用产品经理**：面向办公、教育、内容、客服、营销等场景，用大模型重构用户工作流。
2. **AI Agent 产品经理**：设计多步骤任务自动化、工具调用、权限边界、人机协同和任务评估体系。
3. **AI 平台 / 工具产品经理**：建设 Prompt 管理、模型路由、RAG 平台、评测平台、低代码智能体平台等基础能力。
4. **数据智能 / 决策产品经理**：结合数据分析、预测、推荐和自然语言 BI，提升业务决策效率。
5. **AI 商业化 / 增长产品经理**：围绕 AI 功能定价、转化、留存、成本控制和 ROI 设计商业闭环。

## 使用方式

1. 先打开 [今天开始学习的具体行动](docs/06-start-today.md)，按今天的学习任务开始执行。
2. 根据 [AI 产品经理能力地图](docs/02-skill-map.md) 给自己做能力盘点，找出前三个短板。
3. 按 [30 天学习与作品集冲刺路线图](docs/03-30-day-roadmap.md) 每周推进学习、输出和作品集建设。
4. 每个作品集项目都使用 [`templates/`](templates/) 下的模板沉淀为可展示材料。
5. 每天填写 [`tracker/daily/`](tracker/daily/) 下的学习记录，并在每周填写 [每周复盘与进度追踪](tracker/weekly-review.md)，用结果而不是学习时长衡量进展。

## 30 天成功标准

- 能清晰说明自己要解决的行业问题、目标用户、AI 方案和商业价值。
- 能独立写出 AI 产品 PRD，并定义模型效果、业务效果和用户体验指标。
- 能做基础原型，理解 RAG、Agent、Prompt、评测、成本与安全边界。
- 能拿出 1 个完整作品集案例和 1 个轻量竞品/机会拆解，用 STAR 方式讲清背景、决策、过程和结果。
