# 每日学习记录索引

## 使用规则

- 每天学习开始前先打开当天记录，明确今天只交付什么。
- 每天学习结束后补充「今日产出」「今日复盘」「明天最重要的一件事」。
- 如果当天时间很少，也至少记录 3 行：学了什么、产出了什么、明天做什么。
- 每周复盘时，从当天记录中提取可放入作品集、简历和面试故事的素材。
