# 作品集项目建议

## 选择标准

好的 AI 产品经理作品集项目应该满足：

- 有明确用户和高频任务。
- AI 能明显降低成本、提升效率或改善体验。
- 能定义模型效果、业务效果和用户体验指标。
- 有失败兜底、风险控制和迭代计划。
- 能在 2-4 周内完成可展示版本。

## 项目 1：AI 简历与面试教练

### 适合展示的能力

- 用户任务拆解。
- 内容生成质量评估。
- Prompt 迭代。
- 个性化推荐。

### 核心功能

- 根据目标岗位优化简历要点。
- 提取简历与 JD 的匹配差距。
- 生成面试问题和 STAR 回答建议。
- 提供修改前后对比和理由解释。

### 关键指标

- 简历要点采纳率。
- JD 匹配度提升。
- 用户完成一版简历的时间。
- 用户满意度。

## 项目 2：企业知识库 RAG 问答助手

### 适合展示的能力

- RAG 产品设计。
- 知识来源、引用和可信度设计。
- 模型评测与误差分析。
- 企业场景权限边界。

### 核心功能

- 上传或接入文档。
- 用户自然语言提问。
- 返回答案、引用来源和相关文档。
- 对低置信度问题提示澄清或转人工。

### 关键指标

- 答案准确率。
- 引用命中率。
- 无答案时拒答准确率。
- 人工咨询量下降比例。

## 项目 3：销售线索跟进 Agent

### 适合展示的能力

- Agent 任务链路设计。
- 工具调用和审批节点。
- 增长与商业指标。
- 风险控制。

### 核心功能

- 自动汇总客户信息。
- 生成个性化跟进邮件。
- 安排待办提醒。
- 在发送前请求人工确认。

### 关键指标

- 销售跟进时间节省。
- 邮件回复率。
- 线索转化率。
- 人工修改率。

## 推荐作品集结构

每个项目都按以下结构展示：

1. 背景：用户是谁，原始任务是什么。
2. 问题：痛点、频率、影响和现有替代方案。
3. 方案：AI 如何介入，为什么不是传统方案。
4. 流程：用户流程、模型流程、数据流程和异常流程。
5. 指标：模型指标、业务指标和体验指标。
6. 权衡：准确率、成本、速度、安全和用户控制感。
7. 结果：原型、Demo、实验结果或预期收益。
8. 迭代：下一步优化计划。
